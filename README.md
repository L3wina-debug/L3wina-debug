## About

I am a Master's student in **Artificial Intelligence & Cybersecurity** at Université Ibn Tofail, focused on building **secure, automated and well-tested systems**. My work sits where software engineering meets infrastructure: I write Python tools that automate network operations, I implement applied cryptography with proper key handling and signature verification, and I harden Linux servers with repeatable scripts.

I approach every project with an **engineering mindset**. I write clear requirements, design for failure, add unit tests and dry-run modes, and document so that someone else can run my work. On the AI side, I apply machine learning to security problems such as phishing detection, and I build NLP assistants packaged with Docker.

Field experience at **OCP Group** and **ONEP** gave me hands-on exposure to production networks: firewalls, VPNs, QoS, vulnerability assessments and security log analysis.

**Open To**

- 6-month end-of-studies internship (PFE) starting **February 2027**
- Cybersecurity, network security, SOC, security automation and infrastructure roles
- On-site, hybrid or **remote**; open to relocation
- Working languages: **English, French, Arabic**

## Featured Projects

<details>
<summary><b>Encrypted Messaging App — RSA-OAEP · RSA-PSS · AES-256-GCM</b></summary>
<br/>

A Python command-line messaging tool with hybrid encryption. Each message is encrypted with a fresh AES-256-GCM key wrapped with RSA-OAEP, and signed with RSA-PSS. The signature is verified before anything is decrypted.

| | |
|:--|:--|
| **Stack** | Python · cryptography · pytest |
| **Scale** | Text messages and files up to 8 MiB |
| **Performance** | Symmetric bulk encryption; RSA only wraps the session key |
| **Security** | RSA 2048/3072, password-protected PKCS#8 keys, verify-then-decrypt |
| **Impact** | 20 unit tests covering tampering, wrong keys and wrong signatures |
| **Repository** | [secure-messaging-rsa-aesgcm](https://github.com/L3wina-debug/secure-messaging-rsa-aesgcm) |

The design follows real-world envelope encryption: authenticated encryption for confidentiality and integrity, and digital signatures for authenticity. Any modified ciphertext is rejected before decryption.

</details>
